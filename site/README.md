# site/

The bitdepth.dev pages: static HTML, no build step, no analytics. Deployed by Vercel with the Root Directory set to `site`.

- Hand-written pages: `about/`, `market/`, `method/`, `questions/`, and `index.html` until the leaderboard goes live (then it moves to `compare/`).
- Generated by `python -m probe.site` (do not edit by hand): `lab/` (placeholder preview, noindex, unlinked), and after go-live `index.html`, `m/`, `charts/`, `og/`, `badge/`, `data/v1/`.
- `assets/board.css` and `assets/share.js` serve the generated pages.

Until `scripts/go-live.sh` runs, nothing outside `lab/` names a provider or carries a number from the scorecards, and `lab/` carries only synthetic numbers.

Last deploy trigger: 2026-11-05.
